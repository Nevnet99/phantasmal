## Development

When starting the app, use:

```
bun run dev
```

That starts Vite and launches the Electron window via `vite-plugin-electron`.

Run the full quality gate before committing:

```
bun run check
```

## Stack

- Electron + Lit + TypeScript
- Bun package manager
- oxlint + Prettier
- Vitest
